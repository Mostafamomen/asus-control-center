# Changelog

## 10.2

- Cross-DE support: GNOME 51 and KDE Plasma 6.8.
- Night-light toggle: GNOME settings-daemon DBus or KDE kwinrc + KWin DBus.
- Touchpad enable/disable: GNOME gsettings or xinput fallback for KDE/Wayland.
- Desktop-environment probe (`desktop.cpp`) cached at startup; unsupported controls disabled automatically.

## 1.0.0-rc1

- ASUSCraft release candidate.
- GPU MUX Hybrid and Ultimate support.
- System Diagnosis, System Manager, PC Manager, Software Center.
- Security Center with read-only checks.
- Arabic and English localization improvements.
- Known limitations documented.
